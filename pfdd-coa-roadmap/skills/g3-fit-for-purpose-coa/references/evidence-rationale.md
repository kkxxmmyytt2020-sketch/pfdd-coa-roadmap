# Evidence-based rationale A–H (G3 §IV, Table 2, App. E)

Before the table, state: **intended COU**; **description and justification of the MAH** (patient/
caregiver data on its nature and importance); **COI** and, if not identical to the MAH, how
measuring it informs the MAH (and how multiple COIs combine). FDA weighs evidence for each
component against the uncertainty about it — more uncertainty, more evidence (G3 §II.C). Components
can be dropped or added to fit the case. One study can support several components (cognitive
interviews → C, D, E).

Status per row: **supported** (evidence cited) · **partial** (some evidence; named gap) · **gap**
(no evidence; name the study that would close it).

| | Component | Typical evidence | Notes |
|---|---|---|---|
| **A** | The COI should be assessed by [PRO/ObsRO/ClinRO/PerfO] because… | Self-report feasibility (G1 §II.C.2); nature of the COI (App. A–D) | Proxy is never the reason for an ObsRO; observable behaviour is |
| **B** | The COA captures all important parts of the COI | Concept elicitation, saturation (G2); for COIs far from lived experience, expert input (clinicians, physiologists, psychologists) | Formerly "content validity"; validity is unitary (AERA/APA/NCME 2014). For PerfOs, setup/tasks must cover the function |
| **C** | Administered appropriately | User manual; completion of standardized training at all sites; monitoring during the trial | Relevant when someone administers or assists |
| **D** | Respondents understand instructions and items/tasks as intended | Cognitive interviews against documented intended meanings; range of literacy/numeracy; PerfO instruction pilots | Good questionnaire design (G2 §IV) |
| **E** | Scoring method appropriate | E.1 measurement-model assumptions & fit; E.2 missing-item rule justified; response-option gradations (cognitive interviews) | Specify reflective vs composite model and framework (CTT/IRT/Rasch) |
| **F** | Scores not overly influenced by processes/concepts outside the COI | F.1 DIF / measurement invariance across sex, age, education, culture/language (after qualitative signals); F.2 recall error (recall-period justification); F.3 fatigue/burden; F.4 implementation/design influences — expectation bias (masking), practice effects (PerfO) | Tailor F to the most likely interferences for this COA |
| **G** | Scores not overly influenced by measurement error | Test–retest ICC (stable patients, defined stability criteria, suitable interval); inter-/intra-rater reliability (ObsRO, ClinRO, rated PerfO); IRT information/SE, internal consistency as supplements | Table 3 of G3 lists sources of variation by COA type |
| **H** | Scores correspond to the MAH related to the COI | Direct PRO: often little uncertainty. Indirect COI: **convergent evidence** with measures closer to lived experience (a priori hypothesized correlations, accounting for range restriction/unreliability) and **known-groups evidence** (clinically distinct reference groups with justified cut-offs, not sample quantiles) | The farther the COI from daily life, the more H evidence (Walton; Powers GMP 3). Physiological rationale alone is not enough (Powers) |
