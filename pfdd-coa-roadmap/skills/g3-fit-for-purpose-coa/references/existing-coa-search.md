# Existing COAs: search, label check, branches, modification (G3 §III.C.2; Walton; Powers)

## Where to search (G3 §III.C.2)
Scientific literature (several phrasings: the MAH, the COI, patient terms, synonyms) · measure
repositories and **item banks** (IRT-calibrated, e.g., PROMIS) · clinicaltrials.gov (what trials
actually used) · summaries of prior FDA decisions / drug labels / review documents ·
disease-specific FDA guidances · **FDA COA Qualification Program** and **MDDT** · consensus core
outcome sets from professional groups (but diagnostic criteria ≠ outcome measures — Powers).
Existing COAs with experience in the relevant COU are generally preferred, especially for
well-established COIs (e.g., pain intensity).

For every candidate, record: name and **version**; COI it measures (from its items/tasks, not its
title); population/COU it was developed and tested in; COA type; recall period; scoring; what
evidence exists for each A–H component; licensing/copyright; availability of translations.

## Label check (jingle–jangle for COAs)
- *Same name, different thing:* "Disease X Disability Scale" does not by itself show it measures
  disability in disease X (Walton). Read the items.
- *Different name, same thing:* two differently named instruments may measure your COI — compare
  content, not titles.
- Versions drift: long-standing COAs get modified across studies without reporting, so "the same
  COA" may differ between studies (Walton). Pin the version.
- New COAs: name them for what they actually measure, and name the intended MAH separately (Walton).

## Three branches (G3 §III.C.2.a–c)
| Branch | Situation | What to do |
|---|---|---|
| **a. Use** | Exists for the COI in the same/similar COU | Assess fitness; rationale; summarize supporting evidence; identify missing evidence (e.g., no qualitative work in adolescents) and collect it if needed. Not obliged to use it — a less burdensome COA can be chosen if fit-for-purpose |
| **b. Modify / add evidence** | Exists but for a different COU (e.g., different population) | Evaluate transfer; often cognitive interviews in the new population; discuss evidence needs with FDA; modify only as needed |
| **c. Develop** | None exists | New-COA path (`new-coa-development.md`) |

COAs from registries, natural-history or observational studies may or may not be fit-for-purpose
in a trial COU (G3 §III.C.2.a).

## Modification impact (G3 §III.C.2.b)
| Modification | Likely effect | Evidence |
|---|---|---|
| Paper → electronic, multiple items/page → one item/screen; paper → IVR (small–moderate format changes) with best-practice migration | Usually not score-altering | Usually no new comparability study (O'Donohoe 2023) |
| Instructions / training materials | Small–moderate | Cognitive interviews if meaning could shift |
| Item wording, adding/omitting items, response options, translation | Can alter scores | Cognitive interviews; translation/cultural adaptation best practice; possibly psychometric re-evaluation |
| Item order | Possible priming | Consider testing |
| **Recall period** (e.g., 1 day ↔ 7 days) | Likely alters scores/interpretation — **may in effect create a new measure** | Treat as new-measure evidence needs |
| Scoring algorithm | Alters scores | Re-justify measurement model and interpretation |
| PerfO task change | Can alter scores | Pilot testing; re-establish reliability |

Always check copyright/licensing before modifying (G3 §III.C.2.b).
